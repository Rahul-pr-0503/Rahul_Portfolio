AI_Based_OS

An intelligent, voice-controlled desktop operating layer that turns natural language into system actions.

🚀

Coming Soon

AI_Based_OS Demo will be available here.

Problem

Everyday desktop tasks — opening apps, checking system health, launching files — still require manual navigation. There was no lightweight, always-listening layer that could execute these by voice or text with real intent understanding.

Solution

Building a Python-based OS assistant combining speech recognition with an auto-correcting command parser, so it tolerates imperfect voice input and still fires the right system action — while continuously tracking device health in the background.

Key Features

Voice RecognitionNatural Language Commands Auto-CorrectionApp / File / Browser Launching CPU MonitoringRAM Monitoring Disk MonitoringBattery Monitoring Multi-threaded Execution

Challenges

  • Handling noisy or partial speech input without misfiring commands
  • Keeping the monitoring loop lightweight enough not to compete with foreground apps

Lessons Learned

  • Threading discipline matters as much as the ML model when the app has to feel instant
  • Auto-correction on intent, not just spelling, is what makes voice UX forgiving

GreenGrow AI

A fertilizer recommendation engine that turns raw soil and environmental data into a farmer-ready answer.

Problem

Farmers often lack quick, data-driven guidance on which fertilizer suits their soil's N-P-K profile and local conditions, leading to over- or under-fertilization.

Solution

Trained a Scikit-learn classification pipeline on soil nutrient (N, P, K) and environmental inputs, served through a Flask backend with a Streamlit interface simple enough for non-technical users.
